QlockThreeW32

Flash a clock, from the browser

A blank Seeed XIAO ESP32-S3 becomes a word clock in about a minute — no PlatformIO, no Python, nothing to install. This page writes the whole flash: bootloader, firmware and the configuration interface, in one go.

Before you start

  • Chrome, Edge or Opera on a computer
  • A USB-C cable that carries data
  • A Seeed XIAO ESP32-S3 (Plus, 16 MB flash)

Safari and Firefox cannot do this — they have no Web Serial API. On a phone or tablet there is no port to connect to at all.

This browser cannot flash a device — open this page in Chrome, Edge or Opera on a desktop instead. Web Serial needs a secure connection. This page should already be HTTPS — if you are seeing this, something in between is stripping it.

If the browser cannot find the board

The XIAO's own USB port is not a classic USB-serial bridge, so it does not always drop into the bootloader by itself. If "Connect" shows no port, or the install stalls right at the start:

  1. Unplug the USB cable.
  2. Hold the board's BOOT button down.
  3. Plug the cable back in while still holding it, then let go.
  4. Click "Connect and install" again.

After it's flashed

The clock reboots and, with no WiFi configured yet, opens its own access point named QlockThreeW32. Connect to it from a phone or laptop — a captive portal asks for your network. From then on the clock is reachable at http://qlockthreew32.local or by its address on the network, where the rest of the setup — language, colour, the automatic brightness — happens in the browser.

Firmware and interface updates after this one never need a cable again: they go through the clock's own Update tab, or happen by themselves from the release channel it is set to.

What exactly does this write?

Five parts, at the offsets a factory-fresh XIAO ESP32-S3 needs: the second-stage bootloader, the partition table, the tiny stub that tells it which partition to boot first, the firmware itself, and the filesystem image holding this configuration interface. The "erase" option this tool offers first clears the whole chip, which is the safe default for a board that has never run this firmware before. Reflashing a clock that is already running QlockThreeW32 does not need any of this — use its own Update tab instead, which only ever replaces the two halves that actually changed. Built straight from the latest stable release; see CLAUDE.md for how the firmware itself works.
